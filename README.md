# 潼潼的一週小花課表

📱 潼潼的週課表管理應用

## 使用方式

1. 打開 https://alibabaamyh-cmyk.github.io/tongtong-schedule/
2. 點「🔐 安排課表」設定一週的活動（需要家長密碼）
3. 在對應時段點活動開始計時
4. 計時達 25 分鐘後可以完成
5. 家長可查看完成情況、給愛心、錄音鼓勵

## 功能

- ✅ 每週課表規劃（9 種活動）
- ✅ 內建 25 分鐘計時器
- ✅ 家長檢視 & 錄音鼓勵
- ✅ 完全離線，數據存在平板本機
- ✅ 無需登入、無需網路

## 數據安全

- 所有課表和錄音都保存在 iPad 本機瀏覽器
- GitHub 只託管代碼，不收集任何個人數據
